# Emotion AI Dashboard

A multimodal AI system that combines:

- Text Emotion Detection
- Sentiment Analysis
- Facial Emotion Recognition
- Real-time Webcam Analysis
- Emotion Fusion System

## Technologies
- Python
- Streamlit
- Transformers
- OpenCV
- FER
- Scikit-learn
- XGBoost

## Features
- Text emotion detection
- Facial emotion recognition
- Combined emotion analysis
- Bulk CSV analysis
- ML model training
